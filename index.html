Частые вопросы

Frequently Asked Questions

Пока проект готовится, отвечаем на самые популярные вопросы.

While the project is being prepared, here are answers to common questions.

Когда откроется AninCraft? When will AninCraft launch? +

Мы планируем открыть AninCraft после завершения основных разделов сайта и проверки всех функций.

We plan to launch AninCraft after the main sections of the website are completed and all features are tested.

Моды будут бесплатными? Will the mods be free? +

AninCraft ориентирован на удобный каталог модов и материалов. Условия распространения будут указаны отдельно для каждого материала.

AninCraft is focused on providing a convenient catalog of mods and resources. Distribution terms will be listed separately for each resource.

Для каких версий Minecraft будут моды? Which Minecraft versions will be supported? +

Планируется поддержка популярных версий Minecraft. Точные версии будут указаны в карточках модов.

Popular Minecraft versions are planned to be supported. Exact versions will be listed on each mod page.

Можно ли предложить свой мод? Can I submit my own mod? +

Да. После запуска сайта планируется возможность предложить мод или другой полезный материал.

Yes. After the website launches, we plan to allow users to submit mods and other useful resources.
